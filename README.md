# כדורגל טריוויה

משחק רשת לנייד בעברית (מימין לשמאל): טריוויה על כדורגל ישראלי ואירופי, עם דגש על שנות ה־90 ותחילת שנות ה־2000.

## מצבים

- **נחש את השחקן** — לפי מסלול הקריירה
- **טריוויה** — שאלות אמריקאיות
- **זהה את הסמל** — בקרוב

## הרצה מקומית

```bash
cd app && python3 -m http.server 8787
```

או:

```bash
cd app && ruby -run -e httpd . -p 8787
```

ואז לפתוח בדפדפן את `http://localhost:8787`.

## תוכן

השאלות, השחקנים והמצבים נמצאים בקובץ `app/data.js`.
